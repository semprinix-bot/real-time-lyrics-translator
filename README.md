# Real Time Lyrics Translator

Learn languages through music: synced lyrics of the song playing on Spotify, with a translation under every line.

**Open the app:** https://semprinix-bot.github.io/real-time-lyrics-translator/

- Synced lyrics from [LRCLIB](https://lrclib.net), translations by Google Translate / MyMemory
- Click any word to see its meaning
- Interface and translations in 16 languages

Not affiliated with or endorsed by Spotify.
